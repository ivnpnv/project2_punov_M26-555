# Primitive DB

Учебная база данных в консоли. Пока можно создавать таблицы,
смотреть их список и удалять. Сами записи в таблицах ещё не реализованы.

## Управление таблицами

Для запуска нужны Python 3.12 и uv. В Bash из папки проекта:

uv sync
uv run database


После запуска вводим команды в самой программе. Например, создадим
таблицу users с именем, возрастом и признаком активности:

Введите команду: create_table users name:str age:int is_active:bool
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int, is_active:bool

Введите команду: list_tables
- users

Введите команду: drop_table users
Таблица "users" успешно удалена.

Введите команду: exit


У столбцов доступны три типа: `int`, `str` и `bool`.
`ID:int` добавляется первым автоматически, отдельно указывать его не нужно.
Если таблица уже есть или тип столбца указан неправильно, программа
покажет ошибку и предложит ввести следующую команду.

`list_tables` показывает таблицы, 
`drop_table <имя_таблицы>` удаляет таблицу.
Справку можно посмотреть командой `help`,
 выйти — командой `exit`.

Структура таблиц хранится в `db_meta.json` в той папке, из которой запущена
программа. При следующем запуске из этой же папки таблицы сохранятся.

Проверка кода и сборка пакета:

uv run ruff check .
uv build

## Установка собранного пакета

uv tool install --force dist/primitive_db-0.1.0-py3-none-any.whl
database
