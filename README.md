# Primitive DB

Учебная база данных в консоли. Можно создавать и удалять таблицы,
добавлять, просматривать, менять и удалять записи.

## Управление таблицами

Для запуска нужны Python 3.12 и uv. В Bash из папки проекта:

uv sync
uv run database


После запуска вводим команды в самой программе. Например, создадим
таблицу users с именем, возрастом и признаком активности:

Введите команду: create_table users name:str age:int is_active:bool
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int, is_active:bool

Введите команду: list_tables
- users

Введите команду: drop_table users
Вы уверены, что хотите выполнить "удаление таблицы"? [y/n]: y
Таблица "users" успешно удалена.

Введите команду: exit


У столбцов доступны три типа: `int`, `str` и `bool`.
`ID:int` добавляется первым автоматически, отдельно указывать его не нужно.
Если таблица уже есть или тип столбца указан неправильно, программа
покажет ошибку и предложит ввести следующую команду.

`list_tables` показывает таблицы, 
`drop_table <имя_таблицы>` удаляет таблицу.
Справку можно посмотреть командой `help`,
 выйти — командой `exit`.

Структура таблиц хранится в `db_meta.json` в той папке, из которой запущена
программа. При следующем запуске из этой же папки таблицы сохранятся.

Проверка кода и сборка пакета:

uv run ruff check .
uv build

## CRUD-операции

После запуска `database` можно работать с записями. Для примера нужна
таблица `users` со столбцами `name:str`, `age:int`, `is_active:bool`.

create_table users name:str age:int is_active:bool
insert into users values ("Sergei", 28, true)
select from users
select from users where age = 28
update users set age = 29 where name = "Sergei"
delete from users where ID = 1
info users

`insert` добавляет запись и сам назначает ID. Значения передаются
в порядке столбцов, без ID. Строки нужно писать в кавычках,
целые числа — без кавычек, логические значения — `true` или `false`.

`select` показывает все записи или только те, что подходят под `where`.
Пока поддерживается одно условие равенства, например `age = 28`.

`update` меняет указанные поля у всех подходящих записей. Несколько полей
можно перечислить через запятую: `set age = 29, is_active = false`.
ID менять нельзя. Для `update` и `delete` условие `where` обязательно.

`info` показывает имя таблицы, столбцы и количество записей.
Данные каждой таблицы сохраняются отдельно, например в `data/users.json`.

## Декораторы и кэширование

Ошибки в операциях с таблицами и записями обрабатывает `handle_db_errors`.
Он выводит сообщение при `KeyError`, `ValueError` и `FileNotFoundError`.
После ошибки данные не сохраняются, можно ввести следующую команду.

Перед `drop_table` и `delete` программа запрашивает подтверждение через
`confirm_action`. Только ответ `y` разрешает удаление. Другой ответ,
в том числе пустой, отменяет операцию.

`log_time` показывает время успешного выполнения `insert` и `select`
в секундах с тремя знаками после запятой.

Для повторных запросов `select` используется кэш на основе замыкания
`create_cacher`. Ключ учитывает данные и условие запроса: если записи
изменились, результат вычисляется заново. Кэш хранится в памяти
до завершения программы. Размер кэша пока не ограничен.
